# Adjudication plane -- the Google GenAI SDK, and the only model dependency.
# Pinned against the API this code actually calls:
# genai.Client(api_key=...).models.generate_content(model, contents, config) with
# response_schema + temperature. An earlier pin (0.8.0) was never installed and could
# not resolve at all -- `pip install -r requirements.txt` failed outright, which would
# have broken the reproduce path on any clean machine.
#
# google-adk was listed here for a while and never imported by a single line of this
# codebase. A dependency that exists only to be named in a stack table is worse than no
# dependency, so it is gone; the GenAI SDK below is what the adjudicator actually uses.
google-genai==2.20.0

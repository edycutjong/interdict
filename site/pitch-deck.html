02 · hook
strict liability · 31 CFR
Sanctions compliance is a solved problem — if you're a bank. The statute is strict liability: intent doesn't matter, a wrong payment is a violation. The tooling market simply does not serve small organizations. That gap is the product.
The unlikely hero · the operator this fleet was built for

The delta is her liability.

Amara runs grants at a 12-person humanitarian NGO moving money toward three sanctioned regions. The morning Treasury updates the SDN list, every queued disbursement — grantees, field partners, vendors, payees — becomes her personal federal exposure.

A true hit must be held and reported within 10 business days. A delisting means blocked funds must be released. Today she does it by hand — or not at all.

The solution · one flow, done to the bottom

The whole book, re-screened unattended.

On every OFAC delta, Interdict re-screens the entire 536-counterparty book: true hits held with a written, cited rationale, lookalikes cleared on the record's own evidence, funds released on delisting, the 10-day blocking report drafted.

Architecture · three agents · two planes · one guard

Deterministic code decides what executes.

Failure tolerance is the routing itself: a looping adjudicator hits a hard 2-round-trip cap (counter in Postgres, not in any agent) and lands in a quarantine terminal state; a hallucinated passport number fails citation-vs-record validation at the boundary before anything executes.

05 · architecture
Gemini explains and judges — deterministic code decides what executes
The FEF sub-question asks how the system recovers when a worker loops or hallucinates. Because the planes are separate agents, the oracle guard IS the inter-agent routing logic, not a function call. And it fails closed — a confused agent can never move money.

Autonomy, graded · no self-grading anywhere

Four decisions, four external graders.

HOLD money stops
Adjudicated true hit parks the counterparty and every queued disbursement — idempotent by database constraint.
Judge cross-checks name / DOB / passport on treasury.gov; make challenge reproduces it on any name.
CLEAR payment proceeds
Lookalikes cleared by the deterministic plane on the record's own evidence — weak-alias downweighting per OFAC's own guidance, using the 4,393 real weak aliases in the 08/07/2026 publication.
Agreement table vs OpenSanctions yente, consulted on every adjudication and not only where it agrees; spot-checkable against OFAC Sanctions List Search. Every disagreement documented.
RELEASEmoney moves again
A delisting delta autonomously releases blocked funds and retires the hold.
Live if a sentinel fires (~88% odds — slide 08); guaranteed fallback: a labeled replay of the real Aug 7 removals with the Federal Register notice on screen. Never implied live.
REPORTstatutory artifact
Drafts the OFAC blocking report against the real 10-business-day clock; filed to the append-only ledger.
Report fields verify against the public SDN record; transmission to OFAC stays human — stated honestly.
07 · decisions
each decision acts without a human click — and each has an oracle we don't control
The design rule: no capability is judged by us. Holds grade against Treasury's record, clears against two independent screening oracles, releases against the Federal Register. The 4,393 weak aliases are real feed data — that's what makes false-positive clearing demonstrable rather than staged.

Byte-for-byte deterministic — no RNG, selection by SHA-256 of each entry's uid. If OFAC later delists anyone in this book, the release fires on a name nobody could have known. Git history is the proof.

Measured base rate: 396 removals across 7 OFAC publications — bursty, 96% from two events. So the book is program-stratified: 250 SDNTK (4.5× removal enrichment) · 100 IRAQ2 (13×) · 50 hash-driven remainder.

08 · proof
stratification is disclosed; program membership is public and fixed at seal time — weighting cannot steer the outcome
The easy demo is hindsight replay — pre-seed a name you already know was removed. We sealed the book and its hash in git before any later publication existed, and stratified by public program membership, which raises the odds without touching which names fire. If nothing fires, the fallback replay is labeled as replay — never implied live.
Where it stands · every number below is printed by a script in the repo

Graded, and it beats the oracle.

Screening quality — on names not on the list

Screening the seeded book verbatim scores 1.000 and means nothing: those names were copied out of the publication being searched. So we screen deterministic perturbations — transliterations from OFAC's own alias lists, reordering, dropped particles, transcription confusables. Seeded from SHA-256, so the challenge set is byte-identical on your machine.

  • top-1  0.995  vs  0.840 for yente, the independent oracle — n = 400
  • 1 missed hit in 60 · 0 frozen grantees in 41, against ground truth the screening path never reads — a stratified sample of 101 counterparties, because free-tier Gemini caps requests per day
  • 58 / 1 / 0 — agreements, cases where we were stricter, cases where we were more permissive, across the 59 adjudications in that sample. The last number is the one that matters
  • p50 9.3 ms · p95 68.8 ms · a 400-counterparty pass against the 08/07/2026 publication in 7.6 s. OFAC publishes weekly
  • 134 tests · CI fails if the database tests silently skip

Synthetic — and it says so

  • Treasury's data is unmodified; all figures pinned to the 08/07/2026 publication — the live list is 19,249 records as of 08/20
  • The payment book is ours and synthetic — labelled by origin in the database, on every console screen, and on camera
  • The release leg is a labelled REPLAY; the sentinel book was sealed and committed before any later publication existed
  • No CLEAR-expected row reached the model — all 59 adjudications were HOLD. It is exercised on confirming holds; the clears are the deterministic plane's
  • The 6-hourly poll is local, and it was dead 08-17 to 08-22 — 16 crashes, an OFAC publication inside the gap, the hole visible in the archive index
  • Nothing runs on Google Cloud compute — Firestore's free tier holds the mirrored ledger; agents, Postgres and yente are local

Disclosure plus a reproduction path is the design, not the apology.
